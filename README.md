
# 양 데스크톱 펫

바탕화면에서 자유롭게 돌아다니는 인면양과 함께하세요.
쓰다듬고, 먹이를 주고, 노래를 듣거나 타이머·알람·집중모드를 사용할 수 있는 데스크톱 앱입니다.

## 다운로드

현재 버전: **0.1.1**

| 운영체제 | 설치 파일 |
|---|---|
| Windows x64 | [Windows용 다운로드 · EXE](https://github.com/Ben0Ben0/sheep-desktop-pet-releases/releases/download/v0.1.1/sheep-desktop-pet-0.1.1-win-x64.exe) |
| Mac Apple Silicon | [Mac용 다운로드 · DMG](https://github.com/Ben0Ben0/sheep-desktop-pet-releases/releases/download/v0.1.1/sheep-desktop-pet-0.1.1-mac-arm64.dmg) |

[전체 버전·변경 내역](https://github.com/Ben0Ben0/sheep-desktop-pet-releases/releases)

Intel Mac용은 제공하지 않습니다. 설치할 때는 위 EXE 또는 DMG를 다운로드하세요.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 자유 행동 | 걷기·쉬기·노래·기타·회전 |
| 상호작용 | 쓰다듬기, 풀·사과·석류 먹이기, 공놀이 |
| 외형 설정 | 기본·도트 스타일, 크기·소리 조절 |
| 타이머·알람 | 미니 타이머, 일회성·반복 알람과 메모 |
| 집중모드 | 등록한 사이트 위로 양떼가 나타나 집중을 도와줍니다. |

## 설치 방법

### Windows

1. Windows용 EXE를 다운로드합니다.
2. 설치 프로그램을 실행하고 안내에 따라 설치합니다.
3. 설치한 앱을 실행합니다.

### Mac

1. Mac용 DMG를 다운로드해 엽니다.
2. 앱을 Applications 폴더로 드래그합니다.
3. Applications에서 앱을 실행합니다.

## 기본 조작

- **양 머리 쓰다듬기:** 마우스를 누른 채 문질러 주세요.
- **위치 이동:** 양의 몸을 잡아 끌어주세요.
- **메뉴 열기:** 양을 우클릭하세요.
- **설정 변경:** 우클릭 → 설정에서 조절하세요.
- **집중모드:** 우클릭 → 집중 모드에서 대상 사이트를 등록하세요.

## 업데이트

새 버전 안내가 나타나면 설치 파일을 다운로드하세요. 기존 앱을 완전히 종료한 뒤 새 버전으로 교체하면 됩니다. 자동 설치나 강제 종료는 하지 않습니다.

## 사용 전 확인

- 유료 코드 서명·Apple 공증이 없어 설치 시 보안 경고가 표시될 수 있습니다.
- Mac 집중모드는 접근성 권한이 필요합니다.
- 앱을 종료하면 타이머·알람이 울리지 않습니다.
