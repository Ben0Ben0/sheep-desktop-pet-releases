# 양 데스크톱 펫

양 캐릭터와 함께하는 비공식 팬메이드 데스크톱 펫입니다.

## 제공 기능

- 걷기·노래하기·기타치기·돌아라와 자유 행동
- 쓰다듬기·밥주기·공놀이
- 기본/도트 스타일과 크기·소리·행동 설정
- 타이머·요일 반복 알람과 메모
- macOS 집중모드: 등록한 사이트의 브라우저 창 위에 양떼 표시

## 배포 상태

현재 공개 설치 파일은 준비 중입니다. 실제 배포를 시작하면 이 저장소의 [Releases](https://github.com/Ben0Ben0/sheep-desktop-pet-releases/releases)에 설치 파일·체크섬·변경 내역을 올립니다.

첫 지원 대상은 **macOS Apple Silicon(M1/M2/M3 등, arm64)**입니다. Intel Mac과 Windows는 아직 배포 검증이 끝나지 않았습니다. 집중모드의 브라우저 실기 검증은 macOS/Whale을 기준으로 했습니다.

## 설치와 업데이트

DMG를 열어 앱을 Applications 폴더에 복사하고 실행합니다. 업데이트할 때는 기존 앱을 완전히 종료한 뒤 새 앱으로 교체합니다. 설정과 알람은 앱과 별도 저장 위치에 보관합니다.

스토어 등록·유료 제작자 서명·Apple 공증 없이 제작하는 시험판이므로 macOS 보안 경고나 실행 제한이 나타날 수 있습니다. 다른 Mac의 다운로드 설치 검증은 아직 남아 있습니다.

앱 실행 중 타이머·알람이 동작합니다. 앱이 종료된 동안에는 소리가 울리지 않습니다. 집중모드는 macOS 접근성 권한이 필요합니다.

업데이트 알림은 버전과 변경 내역을 보여주고 다운로드 페이지를 여는 방식입니다. 자동 설치나 강제 재시작은 하지 않습니다. `updates.json`의 다운로드 목록이 비어 있는 동안에는 새 설치 파일을 안내하지 않습니다.
